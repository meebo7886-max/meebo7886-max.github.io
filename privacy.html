rclone-mac privacy policy

Last updated: 11 November 2026.

rclone-mac is a personal tool with one user: the owner of this page. It signs in to that owner's own Google account only.

What Google data it uses

It reads, creates, changes and deletes files in the owner's own Google Drive, so that files from the owner's Mac can be backed up and archived there.

Where the data goes

Only between the owner's Mac and the owner's Google Drive. Nothing is sent to any other server, person or company. Nothing is sold, shared, used for advertising, or used to train any model.

What is stored

The sign-in token stays in a configuration file on the owner's Mac, readable only by the owner's user account. The tool keeps no other record of Google data.

Removing access

The owner can remove the tool's access at any time at myaccount.google.com/permissions.
